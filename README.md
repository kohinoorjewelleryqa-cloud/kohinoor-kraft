# Kohinoor Kraft Jewellery

Custom gold jewellery website for Kohinoor Jewellery W.L.L. (Doha), in English and Arabic.
Built with Next.js, Supabase and Vercel, on the same stack as the silver store.

**What customers can do**
- Browse designs (name jewellery, rings, bangles, earrings, pendants, bridal sets, men's).
- Customise a design: karat (22K/21K/18K), gold colour, size, weight, stones, and a name or text, with a live gold preview in English or Arabic script.
- See an estimated price from today's gold rate, add reference photos, and request a quote. They can also "Create your own" from a sketch.
- Track the order with their reference and mobile number, see the quote, and approve the design drawing online.

**What the shop does in the admin panel (`/admin`, same login as the silver store)**
- Requests & orders: quote builder using today's rate, stage updates, upload design drawings, WhatsApp the customer in their language.
- Designs: add or edit designs in English and Arabic, with photos, karats, weights, making charge per gram and stone options.
- Our work: portfolio photos.
- Gold rates & settings: daily rates, advance %, making time, contact details, categories.

## Set up (about 20 minutes)

### 1. Database (same Supabase project as the silver store)
Supabase → **SQL Editor** → New query → paste all of `supabase/kraft-setup.sql` → **Run**.
It only adds new `kraft_` tables and two photo buckets; the silver store is not touched. Safe to run again.
The result should show 7 categories and 16 designs.

### 2. GitHub
Create a new repository (e.g. `kohinoor-kraft`), open this folder, and drag everything inside it onto the upload page. Commit.

### 3. Vercel
**Add New → Project** → import the repository. Before deploying, add these Environment Variables:

| Name | Value |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | same as the silver store |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | same as the silver store |
| `SUPABASE_SERVICE_ROLE_KEY` | same as the silver store (mark as Secret) |
| `NEXT_PUBLIC_SITE_URL` | this site's address, e.g. `https://www.your-kraft-domain.com` (no slash at the end) |

Then **Deploy**.

### 4. Domain
Vercel → Settings → Domains → add the domain, then add the A and CNAME records in GoDaddy (same as the silver store). Update `NEXT_PUBLIC_SITE_URL` and redeploy.

### 5. Before launch
- Gold rates & settings: check rates, advance %, making time and contact details.
- Replace the sample designs with real ones and photos (Designs → each design), and add portfolio photos.
- Have a native Arabic speaker review the Arabic text, and the owner confirm the Terms (advance refund rule, 5% weight tolerance, 6-month workmanship warranty).

## Daily use
- Every morning: **Gold rates & settings → Save rates**. All prices on the website follow them.
- New requests show a badge on **Requests & orders** and appear live.
- Flow: Request received → Quote sent → Advance received → Design ready for approval → (customer approves online) → Being handcrafted → Polishing and hallmarking → Ready → Delivered.

| `components` | Header, footer, name preview, customiser, tracking |
| `lib/i18n.ts`, `lib/content.ts` | All English and Arabic wording, FAQ, terms, privacy |

| `lib/actions.ts` | Sending requests, photo uploads, tracking, design approval |
